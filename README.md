# TaskFlow — Task Management Web App

TaskFlow is a responsive task management web application built with HTML, CSS, and vanilla JavaScript. It helps users organize daily tasks, track progress, and manage priorities through a clean dashboard interface.

## Features

* Create new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set task priorities
* Add due dates
* Search tasks
* Filter tasks by status
* Sort tasks by date and priority
* View task statistics
* Track completion progress
* Dark and light theme
* Persistent data using browser localStorage
* Responsive design for desktop, tablet, and mobile

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Browser LocalStorage
* Google Fonts

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/taskflow-todo-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation are required.

## How It Works

Task data is stored in the browser's localStorage, allowing tasks to remain available after refreshing the page.
